# Senai-Copia-Modelo

Cópia funcional de repositório modelo

## Descrição

Esta atividade consiste em realizar uma cópia funcional de um repositório modelo disponível publicamente, aplicando versionamento contínuo com Git/GitHub.

## Requisitos

- Clonar um repositório modelo público
- Analisar a estrutura e o funcionamento
- Realizar uma cópia funcional mantendo o histórico de versionamento
- Documentar as alterações realizadas

## Tecnologias

- Git / GitHub
